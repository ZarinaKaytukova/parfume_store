## Онлайн-каталог парфюмерной продукции 

### Описание

Проект представляет собой веб-каталог парфюмерной продукции, разработанный на Django. Приложение позволяет:

- Просматривать товары в виде карточек с изображением, ценой, скидкой и остатком на складе.
- Выполнять поиск по артикулу, названию, производителю, поставщику и категории.
- Фильтровать товары по категории.
- Сортировать товары по остатку на складе.
- Администраторам — добавлять, редактировать и удалять товары через удобный интерфейс.
- Обновлять список товаров без перезагрузки страницы (AJAX).

Проект ориентирован на небольшие парфюмерные магазины, которые хотят получить собственный онлайн-каталог.

### Технологии

- **Python**
- **Django**
- **PostgreSQL**
- **HTML5**
- **CSS3**
- **JavaScript (Fetch API)**
